# Oposiciones Trabajo Social CAM 2026

## Abrir en StackBlitz
1. Entra en https://stackblitz.com/
2. Crea un proyecto **React + Vite** (o importa este ZIP).
3. Sube/descomprime todos los archivos manteniendo la estructura `src/`.
4. StackBlitz instalará las dependencias de `package.json`; si no lo hace, ejecuta `npm install`.
5. Pulsa **Run**.

## Datos y privacidad
El progreso, apuntes, historial y preguntas se guardan en el almacenamiento local del navegador. Exporta copias de seguridad periódicamente. La clave de Gemini solo permanece en memoria durante esa sesión y no se guarda en localStorage. No publiques una clave privada en una aplicación pública; para un despliegue real utiliza un backend/proxy seguro.

## Importante sobre el contenido
El archivo de origen anuncia 83 temas, pero el array `OFFICIAL_TOPICS` que contiene el código no incluye todos: incorpora los 16 generales y solo una parte de los específicos (los identificadores específicos aparecen salteados). La aplicación conserva ese contenido tal como estaba; completa y contrasta el temario oficial antes de usarla como referencia de preparación. Tampoco se ha verificado jurídicamente la normativa citada en los textos.

## Funciones
Panel de progreso, temario y notas, simulacros, banco de preguntas, plazos y normativa, ejercicios prácticos, generador IA Gemini y exportación/importación de copias JSON.
